# Code, data and media rights

Repository code is MIT licensed (root `LICENSE`). Original Atlas editorial exercise data is dedicated under CC0-1.0; see `DATA-LICENSE.md`. External contributions must include a compatible license grant or a record-specific license and attribution. An upstream repository-wide Unlicense notice does not prove that every third-party image can be redistributed. Atlas has imported no images or text from free-exercise-db in this draft.

Before adding media, document the actual creator, source URL, precise license and a URL evidencing redistribution permission. Store the file locally under `media/exercises/`; record its path and alt text on the exercise. If any fact cannot be confirmed, leave `media` absent. The web explorer must show an honest empty state. Any future third-party media with attribution terms needs an inventory entry and a release review.

The 30 current technique descriptions are original editorial drafts with `reviewStatus: pending`. The words are available under CC0, but their movement accuracy is not yet independently reviewed. A maintainer should arrange a named subject-matter review before describing the data as verified.
