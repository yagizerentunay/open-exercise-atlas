# Code, data and media rights

Repository code is MIT licensed (root `LICENSE`). Original Atlas editorial exercise data is dedicated under CC0-1.0; see `DATA-LICENSE.md`. External contributions must include a compatible license grant or a record-specific license and attribution. An upstream repository-wide Unlicense notice does not prove that every third-party image can be redistributed. Atlas has imported no images or text from free-exercise-db in this draft. Text and illustrations migrated from Monk Mode are the repository owner's own work.

A media asset may carry a record-specific license when its redistribution is evidenced. The accepted licenses are the allow-list `CC0-1.0` and `MIT`; the Monk Mode illustrations are MIT as published in `yagizerentunay/monk-mode` (see [media provenance](media-provenance.md)). Adding a license value needs a schema change.

Before adding media, document the actual creator, source URL, precise license and a URL evidencing redistribution permission. Store the file locally under `media/exercises/`; record its path and alt text on the exercise. If any fact cannot be confirmed, leave `media` absent. The web explorer shows an honest empty state for exercises without media. The original bench press illustration is recorded in [media provenance](media-provenance.md). Record any future third-party media attribution in the asset inventory.

Exercise descriptions are general reference text, not individualized coaching or medical advice. Original Atlas data is dedicated under CC0-1.0; migrated Monk Mode material keeps its recorded license and attribution.
