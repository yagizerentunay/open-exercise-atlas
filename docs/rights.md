# Code, data and media rights

Repository code is MIT licensed (root `LICENSE`). Original Atlas editorial exercise data is dedicated under CC0-1.0; see `DATA-LICENSE.md`. External contributions must include a compatible license grant or a record-specific license and attribution. An upstream repository-wide Unlicense notice does not prove that every third-party image can be redistributed. Atlas has imported no images or text from free-exercise-db in this draft. Text and illustrations migrated from Monk Mode are the repository owner's own work.

A media asset may carry a record-specific license when its redistribution is evidenced. The accepted licenses are the allow-list `CC0-1.0` and `MIT`; the Monk Mode illustrations are MIT as published in `yagizerentunay/monk-mode` (see [media provenance](media-provenance.md)). A new license value needs a documented review and a schema change.

Before adding media, document the actual creator, source URL, precise license and a URL evidencing redistribution permission. Store the file locally under `media/exercises/`; record its path and alt text on the exercise. If any fact cannot be confirmed, leave `media` absent. The web explorer shows an honest empty state for exercises without media. The original bench press illustration is recorded in [media provenance](media-provenance.md). Any future third-party media with attribution terms needs an inventory entry and a release review.

All current technique descriptions are original editorial drafts or migrated Monk Mode text with `reviewStatus: pending`. The words are available under CC0, but their movement accuracy is not yet independently reviewed. A maintainer should arrange a named subject-matter review before describing the data as verified.
