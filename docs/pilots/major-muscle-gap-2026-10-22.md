# Major-muscle catalog follow-up — 22 October 2026

A further check of the plate-loaded lineup found eight more distinct machines: independent-arm horizontal and decline chest presses, a Super Squat Press, an Assisted Nordic Hamstring Curl, a D.Y. Row, a Super Incline Press, a machine shrug, and a machine gripper. Later scans added a dedicated tibialis dorsi-flexion machine, Barbell Bulgarian Split Squat, Cable Romanian Deadlift, and Smith Machine Romanian Deadlift.

## Why they are distinct

- **V-Squat:** Atlas already contains Hack Squat, Pendulum Squat, Belt Squat, and Smith Machine Squat. The Hammer Strength V-Squat uses a supported curved arc; its manufacturer distinguishes this from the Hack Squat's linear track and the deeper pendulum pattern. The V-Squat is sold as a distinct plate-loaded machine.
- **Vertical Leg Press:** Atlas's general Leg Press uses a seated setup. The vertical model has the athlete lying supine and driving a guided platform directly above the hips, a distinct body position and resistance path. Body-Solid and Panatta each list a dedicated vertical leg-press machine.
- **Horizontal bench press:** Atlas has a selectorized chest press and a plate-loaded iso-lateral incline press, but no plate-loaded horizontal bench press. The Hammer Strength model uses independent arms and a converging/diverging path, rather than the selectorized machine's shared press mechanism.
- **Decline chest press:** Atlas has a selectorized decline press, but no independent-arm, plate-loaded decline station. The Hammer Strength machine uses separate arms and a downward-forward path from an upright seated position.
- **Super Squat Press:** Atlas has hack, pendulum, V-Squat, leg press, and belt squat movements. This newer machine adds articulating footplates, a four-bar linkage, and independent work arms for unilateral leg training.
- **Assisted Nordic Hamstring Curl:** Atlas has the unassisted bodyweight Nordic curl and machine knee curls. The counterbalanced machine allows assistance to be adjusted by loading its assistance horns, making the Nordic pattern scalable while retaining its forward-fall eccentric action.
- **D.Y. Row:** Existing rows cover seated, low, high, T-bar, and unilateral patterns. The D.Y. machine adds an underhand grip, overhead pivot, and shoulder-aligned downward/backward arc with chest support.
- **Super Incline Press:** Existing machine shoulder and incline presses cover separate conventional angles. The Super Incline has a steeper upward-forward path between those presses and independent work arms.
- **Machine shrug:** Atlas has cable, barbell, and dumbbell shrugs but no plate-loaded station with fixed side handles and both seated/standing positions.
- **Machine gripper:** Atlas has a spring hand gripper, but not the seated plate-loaded unit with pronated and supinated grip positions. This adds adjustable loaded grip work while retaining the same hand-grip family.
- **Tibia Dorsi-Flexion:** Atlas has a wall-supported tibialis raise but no dedicated machine. The plate-loaded seated device stabilizes the thigh and applies resistance at the forefoot for ankle dorsiflexion, complementing calf-raise work.
- **Barbell Bulgarian Split Squat:** Atlas has bodyweight and dumbbell records but no barbell-loaded version. The bar across the upper back allows a distinct loading progression while preserving the rear-foot-elevated unilateral squat.
- **Cable Romanian Deadlift:** Atlas has barbell and dumbbell RDLs and a cable pull-through. The cable RDL faces the pulley and tracks the handle along the front of the legs, unlike the pull-through's away-facing rope path between the legs.
- **Smith Machine Romanian Deadlift:** Atlas has free-weight RDLs and other Smith movements but no Smith RDL. Its guided bar path allows a machine-specific hinge setup while retaining the front-of-leg RDL path.
