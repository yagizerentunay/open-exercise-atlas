# First release checklist

- [ ] English and Turkish translations are present for the published catalog.
- [ ] Source and reuse rights are recorded for adapted text and media.
- [ ] `npm run validate`, `npm run data:check`, `npm run lint`, `npm test`, and `npm run build` pass.
- [ ] A local static preview and keyboard navigation are checked.
- [ ] GitHub Pages job passes after an authorized push; deployment URL is checked.
- [ ] Version tag, changelog, data schema migration notes and release archive are prepared.
- [ ] Monk Mode legacy ID map is checked against saved-data fixtures before any integration.
